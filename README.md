# Informe Maestro — Reingeniería de Cuentas Médicas

Este repositorio contiene el **Informe Maestro de Reingeniería de Cuentas Médicas**, un documento interactivo que consolida el estado del proyecto de transformación y automatización del ciclo de vida de facturación y pagos a prestadores de salud.

## Visualización

El informe se sirve como sitio estático vía **GitHub Pages**:

🔗 [Ver Informe](https://monicarojas-maker.github.io/Informe-Maestro--Cuentas-M-dicas/)

## Contenido

- Resumen ejecutivo con KPIs objetivo
- Cronograma maestro por fases e iteraciones
- Arquitectura del sistema (diagrama de componentes)
- Dependencias y riesgos identificados
- Mapa de APIs por squad
- Matriz de coherencia (discrepancias detectadas)

## Tecnología

El informe es un archivo HTML estático autocontenido (sin dependencias externas). Se sirve directamente con GitHub Pages sin procesamiento Jekyll.
